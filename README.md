# روشنا | راهنمای مراقبت و جوانسازی پوست

یک وب‌سایت فارسی، راست‌چین و واکنش‌گرا برای آشنایی عمومی با مراقبت از پوست و روش‌های جوانسازی.

## امکانات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- محتوای فارسی با چیدمان راست‌چین
- معرفی روتین پایه صبح و شب
- آشنایی مقدماتی با رتینوئیدها، ویتامین C، هیالورونیک اسید و نیاسینامید
- معرفی کلی روش‌های تخصصی و نکات ایمنی
- پرسش‌های پرتکرار با بخش‌های بازشونده
- منوی موبایل بدون نیاز به کتابخانه جانبی

## اجرا
فایل `index.html` را در مرورگر باز کن. برای انتشار رایگان می‌توانی GitHub Pages را از تنظیمات مخزن فعال کنی.

## ساختار پروژه
- `index.html` — ساختار و محتوای صفحه
- `styles.css` — ظاهر، رنگ‌ها و واکنش‌گرایی
- `script.js` — رفتار منوی موبایل و سال پانوشت

## نکته سلامت
این وب‌سایت محتوای آموزشی عمومی دارد و جایگزین تشخیص یا توصیه پزشک نیست. انتخاب درمان، دارو یا روش‌های کلینیکی باید با ارزیابی متخصص پوست انجام شود. در صورت بارداری یا اقدام به بارداری، درباره مصرف رتینوئیدها با پزشک مشورت کنید.

## مجوز
این پروژه برای استفاده و توسعه شخصی ارائه شده است.
